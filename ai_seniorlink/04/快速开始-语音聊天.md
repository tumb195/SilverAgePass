# 快速开始 - 语音聊天（5分钟上手）

## 🚀 最简单的实现方式

### 步骤1: 创建 HTML 文件

创建 `voice-chat.html`：

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>语音聊天</title>
</head>
<body>
    <h1>语音聊天</h1>
    <button onclick="connect()">连接</button>
    <button onclick="startRecording()">开始录音</button>
    <button onclick="stopRecording()">停止录音</button>
    <div id="log"></div>

    <script>
        // ⚠️ 修改为你的服务器地址
        const WS_URL = 'ws://192.168.0.103:8000/ws/voice-chat';
        
        let ws = null;
        let mediaRecorder = null;
        let mediaStream = null;

        // 1. 连接 WebSocket
        function connect() {
            ws = new WebSocket(WS_URL);
            ws.onopen = () => log('✅ 连接成功');
            ws.onmessage = (e) => {
                if (e.data instanceof Blob) {
                    playAudio(e.data);
                }
            };
            ws.onerror = (e) => log('❌ 连接错误');
        }

        // 2. 开始录音
        async function startRecording() {
            // 获取麦克风
            mediaStream = await navigator.mediaDevices.getUserMedia({ audio: true });
            
            // 创建录音器
            mediaRecorder = new MediaRecorder(mediaStream);
            
            // 发送音频数据
            mediaRecorder.ondataavailable = (e) => {
                if (e.data.size > 0 && ws.readyState === WebSocket.OPEN) {
                    ws.send(e.data);
                }
            };
            
            // 开始录音（每100ms发送一次）
            mediaRecorder.start(100);
            log('🎤 开始录音...');
        }

        // 3. 停止录音
        function stopRecording() {
            if (mediaRecorder) {
                mediaRecorder.stop();
                log('⏹️ 停止录音');
            }
        }

        // 4. 播放音频
        function playAudio(blob) {
            const audio = new Audio(URL.createObjectURL(blob));
            audio.play();
            log('🔊 播放音频');
        }

        // 日志
        function log(msg) {
            document.getElementById('log').innerHTML += '<div>' + msg + '</div>';
        }
    </script>
</body>
</html>
```

### 步骤2: 打开文件

1. 在浏览器中打开 `voice-chat.html`
2. 点击"连接"按钮
3. 允许麦克风权限
4. 点击"开始录音"
5. 说话，等待回复

## 🔧 如果遇到问题

### 问题1: 无法访问麦克风
- **解决**: 检查浏览器权限设置
- **Chrome**: 地址栏左侧的锁图标 → 网站设置 → 麦克风

### 问题2: WebSocket 连接失败
- **解决**: 
  1. 确认后端服务运行：`http://192.168.0.103:8000/api/health`
  2. 检查防火墙设置
  3. 确认环境变量已配置

### 问题3: 没有声音
- **解决**: 
  1. 检查浏览器音量
  2. 检查系统音量
  3. 查看浏览器控制台错误信息
