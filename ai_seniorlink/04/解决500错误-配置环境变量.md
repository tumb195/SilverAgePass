# 解决 500 Internal Server Error

## 🔍 问题原因

出现 **500 Internal Server Error** 是因为**环境变量未配置**。

语音功能需要配置以下环境变量：
- `DOUBAO_APP_ID` - 豆包应用ID
- `DOUBAO_ACCESS_TOKEN` - 豆包访问令牌
- `DOUBAO_APP_KEY` - 豆包应用密钥

---

## ✅ 解决方案：配置环境变量

### 方法1: PowerShell 临时配置（当前会话有效）

```powershell
# 设置环境变量
$env:DOUBAO_APP_ID="你的应用ID"
$env:DOUBAO_ACCESS_TOKEN="你的访问令牌"
$env:DOUBAO_APP_KEY="你的应用密钥"

# 验证是否设置成功
echo $env:DOUBAO_APP_ID
echo $env:DOUBAO_ACCESS_TOKEN
echo $env:DOUBAO_APP_KEY
```

**注意**: 关闭 PowerShell 后需要重新设置。

### 方法2: 系统环境变量（永久配置）

#### Windows 10/11:

1. 按 `Win + R`，输入 `sysdm.cpl`，回车
2. 点击 **高级** 标签
3. 点击 **环境变量** 按钮
4. 在 **用户变量** 或 **系统变量** 中点击 **新建**
5. 添加以下三个变量：
   - 变量名: `DOUBAO_APP_ID`，变量值: `你的应用ID`
   - 变量名: `DOUBAO_ACCESS_TOKEN`，变量值: `你的访问令牌`
   - 变量名: `DOUBAO_APP_KEY`，变量值: `你的应用密钥`
6. 点击 **确定** 保存
7. **重启 PowerShell 或命令行窗口**使配置生效

#### 通过 PowerShell 设置系统环境变量（管理员权限）

```powershell
# 需要以管理员身份运行 PowerShell
[System.Environment]::SetEnvironmentVariable("DOUBAO_APP_ID", "你的应用ID", "User")
[System.Environment]::SetEnvironmentVariable("DOUBAO_ACCESS_TOKEN", "你的访问令牌", "User")
[System.Environment]::SetEnvironmentVariable("DOUBAO_APP_KEY", "你的应用密钥", "User")
```

### 方法3: 创建 .env 文件（推荐开发环境）

在项目根目录创建 `.env` 文件：

```env
DOUBAO_APP_ID=你的应用ID
DOUBAO_ACCESS_TOKEN=你的访问令牌
DOUBAO_APP_KEY=你的应用密钥
DOUBAO_RESOURCE_ID=volc.speech.dialog
DOUBAO_REALTIME_URL=wss://openspeech.bytedance.com/api/v3/realtime/dialogue
```

**注意**: 需要确保后端代码支持读取 `.env` 文件（项目已安装 `python-dotenv`）。

---

## 🔄 重启后端服务

配置环境变量后，**必须重启后端服务**才能生效：

1. 停止当前运行的后端服务（按 `Ctrl+C`）
2. 重新启动：
   ```powershell
   cd backend
   python run_server.py
   ```

## 🧪 测试配置

配置完成后，再次测试：

```powershell
Invoke-RestMethod -Uri "http://127.0.0.1:8000/api/voice-chat/test" -Method Post -ContentType "application/json" -Body "{}"
```

### 成功响应示例：

```json
{
    "ok": true,
    "detail": "实时语音 API 连接成功，返回首条事件。",
    "server_event": {
        "event_type": "...",
        "data": {...}
    }
}
```

### 如果环境变量未配置，现在会返回：

```json
{
    "detail": "语音功能配置错误：app_id、access_key、app_key 均不能为空。请配置环境变量 DOUBAO_APP_ID、DOUBAO_ACCESS_TOKEN、DOUBAO_APP_KEY"
}
```

## ⚠️ 注意事项

1. **环境变量值不要有空格**，特别是开头和结尾
2. **不要使用引号**包裹值（PowerShell 会自动处理）
3. **重启服务**后才能生效
4. **获取凭证**: 需要在火山引擎（豆包）控制台申请 API 凭证
