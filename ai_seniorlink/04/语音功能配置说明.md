## 🔌 API 接口说明

### 1. WebSocket 实时语音接口

**连接地址**: `ws://127.0.0.1:8000/ws/voice-chat`

**功能**: 
- 双向实时语音通信
- 前端发送音频数据 → 后端转发给豆包
- 豆包返回音频数据 → 后端转发回前端

**使用示例** (JavaScript):

```javascript
const ws = new WebSocket('ws://127.0.0.1:8000/ws/voice-chat');

// 连接成功
ws.onopen = () => {
    console.log('语音连接已建立');
};

// 接收音频数据
ws.onmessage = (event) => {
    if (event.data instanceof Blob) {
        // 处理音频数据
        const audioBlob = event.data;
        // 播放音频或进一步处理
    } else {
        // 处理文本消息
        console.log('收到文本:', event.data);
    }
};

// 发送音频数据
function sendAudio(audioData) {
    ws.send(audioData);  // audioData 是 ArrayBuffer 或 Blob
}

// 发送文本消息
ws.send('文本消息');
```

### 2. 语音连接测试接口

**请求**: `POST /api/voice-chat/test`

**请求体**:
```json
{
    "connect_id": "test-123",
    "timeout_seconds": 15,
    "session_params": {}
}
```

**成功响应**:
```json
{
    "ok": true,
    "detail": "实时语音 API 连接成功，返回首条事件。",
    "server_event": {
        "event_type": "...",
        "data": {...}
    }
}
```

**失败响应**:
- HTTP 状态码: `502`
- 响应体:
```json
{
    "detail": "实时语音 API 连接失败：..."
}
```

**测试示例** (Python):

```python
import requests

response = requests.post(
    "http://127.0.0.1:8000/api/voice-chat/test",
    json={
        "connect_id": "test-123",
        "timeout_seconds": 15,
        "session_params": {}
    }
)
print(response.json())
```

## 🚀 使用流程

1. **配置环境变量** - 设置豆包实时语音API的认证信息
2. **启动后端服务** - 运行 `python backend/run_server.py`
3. **测试连接** - 调用 `/api/voice-chat/test` 接口测试连接
4. **建立WebSocket连接** - 前端通过 `ws://127.0.0.1:8000/ws/voice-chat` 建立连接
5. **发送/接收音频** - 通过WebSocket双向传输音频数据

## 📝 注意事项

1. **环境变量必须配置** - 否则语音功能无法使用
2. **WebSocket连接** - 需要前端配合实现音频采集和播放
3. **音频格式** - 需要根据豆包API文档确定支持的音频格式
4. **网络要求** - WebSocket连接需要稳定的网络环境

## 🔍 故障排查

如果语音功能无法使用，请检查：

1. ✅ 环境变量是否正确配置
2. ✅ 后端服务是否正常启动
3. ✅ 网络连接是否正常
4. ✅ 豆包API凭证是否有效
5. ✅ 使用 `/api/voice-chat/test` 接口测试连接
