# 项目启动说明

## 快速启动

### 方式一：使用启动脚本（推荐）

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 进入backend目录
cd backend

# 3. 启动服务器
python run_server.py
```

启动脚本会自动：
- 获取本机IPv4地址
- 显示本地和网络访问地址
- 使用 `0.0.0.0` 监听所有网络接口，支持通过IPv4地址访问

### 方式二：直接使用 uvicorn

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 进入backend目录
cd backend

# 3. 启动服务（监听所有网络接口）
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

## 环境变量配置（可选）

如果需要使用豆包API功能，需要配置以下环境变量：

**Windows PowerShell:**
```powershell
$env:ARK_ACCESS_TOKEN="你的访问令牌"
$env:ARK_MODEL_ID="你的模型ID"
$env:ARK_CHAT_COMPLETIONS_URL="https://ark.cn-beijing.volces.com/api/v3/chat/completions"
```

**Windows CMD:**
```cmd
set ARK_ACCESS_TOKEN=你的访问令牌
set ARK_MODEL_ID=你的模型ID
set ARK_CHAT_COMPLETIONS_URL=https://ark.cn-beijing.volces.com/api/v3/chat/completions
```

**Linux/Mac:**
```bash
export ARK_ACCESS_TOKEN="你的访问令牌"
export ARK_MODEL_ID="你的模型ID"
export ARK_CHAT_COMPLETIONS_URL="https://ark.cn-beijing.volces.com/api/v3/chat/completions"
```

或者创建 `.env` 文件（需要安装 `python-dotenv`）：
```
ARK_ACCESS_TOKEN=你的访问令牌
ARK_MODEL_ID=你的模型ID
ARK_CHAT_COMPLETIONS_URL=https://ark.cn-beijing.volces.com/api/v3/chat/completions
```

## 访问地址

启动成功后，可以通过以下地址访问：

- **本地访问**: http://127.0.0.1:8000
- **网络访问**: http://<你的IPv4地址>:8000
- **API文档**: http://127.0.0.1:8000/docs
- **健康检查**: http://127.0.0.1:8000/api/health
- **获取IP地址**: http://127.0.0.1:8000/api/ip

## 停止服务

按 `Ctrl+C` 停止服务
