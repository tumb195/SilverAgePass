# 测试语音接口的各种方法

## ⚠️ 重要提示

**JavaScript 代码只能在浏览器控制台运行，不能在 PowerShell 中运行！**

---

## 🌐 方法1: 浏览器控制台（推荐）

### 步骤：
1. 打开浏览器（Chrome、Edge、Firefox等）
2. 按 `F12` 打开开发者工具
3. 切换到 **Console（控制台）** 标签
4. 粘贴以下代码并回车：

```javascript
fetch('http://127.0.0.1:8000/api/voice-chat/test', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json',
    },
    body: JSON.stringify({
        connect_id: 'test-' + Date.now(),
        timeout_seconds: 15,
        session_params: {}
    })
})
.then(response => response.json())
.then(data => {
    console.log('✅ 测试结果:', data);
    if (data.ok) {
        console.log('连接成功！');
    }
})
.catch(error => console.error('❌ 错误:', error));
```

## 💻 方法2: PowerShell（Windows）

### 使用 Invoke-RestMethod

```powershell
$body = @{
    connect_id = "test-123"
    timeout_seconds = 15
    session_params = @{}
} | ConvertTo-Json

Invoke-RestMethod -Uri "http://127.0.0.1:8000/api/voice-chat/test" `
    -Method Post `
    -ContentType "application/json" `
    -Body $body
```

### 使用 Invoke-WebRequest（更详细）

```powershell
$body = @{
    connect_id = "test-123"
    timeout_seconds = 15
    session_params = @{}
} | ConvertTo-Json

$response = Invoke-WebRequest -Uri "http://127.0.0.1:8000/api/voice-chat/test" `
    -Method Post `
    -ContentType "application/json" `
    -Body $body

$response.Content | ConvertFrom-Json
```

### 最简版本（空参数）

```powershell
Invoke-RestMethod -Uri "http://127.0.0.1:8000/api/voice-chat/test" `
    -Method Post `
    -ContentType "application/json" `
    -Body "{}"
```

## 🐧 方法3: curl（命令行）

### Windows PowerShell

```powershell
curl.exe -X POST http://127.0.0.1:8000/api/voice-chat/test `
    -H "Content-Type: application/json" `
    -d '{\"connect_id\": \"test-123\", \"timeout_seconds\": 15, \"session_params\": {}}'
```

### Windows CMD

```cmd
curl -X POST http://127.0.0.1:8000/api/voice-chat/test ^
    -H "Content-Type: application/json" ^
    -d "{\"connect_id\": \"test-123\", \"timeout_seconds\": 15, \"session_params\": {}}"
```

### Linux/Mac

```bash
curl -X POST http://127.0.0.1:8000/api/voice-chat/test \
    -H "Content-Type: application/json" \
    -d '{"connect_id": "test-123", "timeout_seconds": 15, "session_params": {}}'
```

## 📱 方法5: Postman 或类似工具

1. 打开 Postman
2. 选择方法：**POST**
3. URL: `http://127.0.0.1:8000/api/voice-chat/test`
4. Headers: 添加 `Content-Type: application/json`
5. Body: 选择 **raw** 和 **JSON**，输入：
```json
{
    "connect_id": "test-123",
    "timeout_seconds": 15,
    "session_params": {}
}
```
6. 点击 **Send**

## 📋 快速测试脚本

### PowerShell 测试脚本（保存为 test.ps1）

```powershell
# test.ps1
$uri = "http://127.0.0.1:8000/api/voice-chat/test"
$body = @{
    connect_id = "test-$(Get-Date -Format 'yyyyMMddHHmmss')"
    timeout_seconds = 15
    session_params = @{}
} | ConvertTo-Json

Write-Host "正在测试语音接口..." -ForegroundColor Yellow
Write-Host "URL: $uri" -ForegroundColor Cyan
Write-Host "Body: $body" -ForegroundColor Cyan
Write-Host ""

try {
    $response = Invoke-RestMethod -Uri $uri `
        -Method Post `
        -ContentType "application/json" `
        -Body $body
    
    Write-Host "✅ 测试成功！" -ForegroundColor Green
    $response | ConvertTo-Json -Depth 10
} catch {
    Write-Host "❌ 测试失败！" -ForegroundColor Red
    Write-Host $_.Exception.Message -ForegroundColor Red
}
```

**运行方式**:
```powershell
.\test.ps1
```

## ⚠️ 常见错误

### 错误1: 在 PowerShell 中运行 JavaScript
**错误**: 语法错误，PowerShell 不支持 JavaScript
**解决**: 使用浏览器控制台或 PowerShell 的 `Invoke-RestMethod`

### 错误2: 405 Method Not Allowed
**原因**: 使用了 GET 方法
**解决**: 必须使用 POST 方法

### 错误3: 400 Bad Request
**原因**: JSON 格式错误或缺少 Content-Type
**解决**: 确保设置了 `Content-Type: application/json` 和有效的 JSON 格式
