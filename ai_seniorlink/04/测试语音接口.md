# 测试语音接口的正确方法

## ❌ 错误方式

直接在浏览器访问 `http://127.0.0.1:8000/api/voice-chat/test` 会返回 **405 Method Not Allowed**

因为浏览器默认使用 GET 方法，而这个接口只支持 POST 方法。

---

## ✅ 正确方式

### 方法1: 使用 curl（命令行）

```bash
curl -X POST http://127.0.0.1:8000/api/voice-chat/test \
  -H "Content-Type: application/json" \
  -d "{\"connect_id\": \"test-123\", \"timeout_seconds\": 15, \"session_params\": {}}"
```

**Windows PowerShell**:
```powershell
curl.exe -X POST http://127.0.0.1:8000/api/voice-chat/test `
  -H "Content-Type: application/json" `
  -d '{\"connect_id\": \"test-123\", \"timeout_seconds\": 15, \"session_params\": {}}'
```

### 方法2: 使用 Postman 或类似工具

1. 方法选择: **POST**
2. URL: `http://127.0.0.1:8000/api/voice-chat/test`
3. Headers: 
   - `Content-Type: application/json`
4. Body (选择 raw JSON):
```json
{
    "connect_id": "test-123",
    "timeout_seconds": 15,
    "session_params": {}
}
```

### 方法3: 使用 JavaScript fetch

```javascript
fetch('http://127.0.0.1:8000/api/voice-chat/test', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json',
    },
    body: JSON.stringify({
        connect_id: 'test-123',
        timeout_seconds: 15,
        session_params: {}
    })
})
.then(response => response.json())
.then(data => {
    console.log('测试结果:', data);
    if (data.ok) {
        console.log('✅ 连接成功:', data.detail);
    } else {
        console.error('❌ 连接失败:', data.detail);
    }
})
.catch(error => {
    console.error('请求错误:', error);
});
```

### 方法4: 使用 Python requests

```python
import requests

response = requests.post(
    'http://127.0.0.1:8000/api/voice-chat/test',
    json={
        'connect_id': 'test-123',
        'timeout_seconds': 15,
        'session_params': {}
    }
)

print(response.json())
```

## 🎯 直接使用 WebSocket（推荐）

**实际上，测试接口是可选的！** 你可以直接使用 WebSocket 接口进行语音聊天：

```javascript
// 直接建立 WebSocket 连接
const ws = new WebSocket('ws://127.0.0.1:8000/ws/voice-chat');

ws.onopen = () => {
    console.log('✅ 语音连接已建立');
};

ws.onmessage = (event) => {
    if (event.data instanceof Blob) {
        // 处理音频数据
        const audio = new Audio(URL.createObjectURL(event.data));
        audio.play();

        console.log('收到消息:', event.data);
```

## 📋 接口说明

### POST /api/voice-chat/test

**用途**: 测试与豆包实时语音API的连接

**请求体**:
```json
{
    "connect_id": "test-123",      // 可选，连接ID
    "timeout_seconds": 15,         // 可选，超时时间（秒）
    "session_params": {}          // 可选，会话参数
}
```

**成功响应**:
```json
{
    "ok": true,
    "detail": "实时语音 API 连接成功，返回首条事件。",
    "server_event": {
        "event_type": "...",
        "data": {...}
    }
}
```

**失败响应**:
- HTTP 状态码: `502`
- 响应体:
```json
{
    "detail": "实时语音 API 连接失败：..."
}
```

## 🔍 在浏览器中测试

如果你想在浏览器中测试，可以使用浏览器控制台：

1. 打开浏览器开发者工具（F12）
2. 切换到 Console 标签
3. 粘贴以下代码：

```javascript
fetch('http://127.0.0.1:8000/api/voice-chat/test', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json',
    },
    body: JSON.stringify({
        connect_id: 'test-' + Date.now(),
        timeout_seconds: 15,
        session_params: {}
    })
})
.then(res => res.json())
.then(data => console.log('测试结果:', data))
.catch(err => console.error('错误:', err));
```

---

## ⚠️ 注意事项

1. **必须使用 POST 方法**，不能使用 GET
2. **必须设置 Content-Type 为 application/json**
3. **请求体必须是有效的 JSON 格式**
4. **需要配置环境变量**（DOUBAO_APP_ID, DOUBAO_ACCESS_TOKEN, DOUBAO_APP_KEY）才能正常工作
