# 银龄通行证前端完整测试平台

## 📖 简介

这是一个为银龄通行证后端API设计的**完整功能测试平台**，涵盖了所有后端接口，用于全面测试系统的各项功能。

## 🚀 快速开始

### 1. 启动后端服务

```bash
mvn spring-boot:run
```

### 2. 访问测试平台

在浏览器中打开：
```
http://localhost:8080/silveragepass/index.html
```

## 🎯 完整功能模块

### 1. 认证管理 (🔐) - 4个接口

#### ✅ 用户登录
- 接口：`POST /api/auth/login`
- 功能：使用用户名和密码登录
- 测试数据：
  - 管理员：`admin` / `admin123`

#### ✅ 发送短信验证码
- 接口：`POST /api/auth/send-code`
- 功能：发送短信验证码（60秒防刷限制）
- 特点：同一手机号60秒内只能发送一次
- 测试手机号：`13800138000`

#### ✅ 手机验证码登录
- 接口：`POST /api/auth/phone-login`
- 功能：使用手机号和验证码登录
- 说明：如果手机号未注册，将自动创建新用户

#### ✅ 用户注册
- 接口：`POST /api/auth/register`
- 功能：新用户注册
- 必填项：用户名、密码、手机号、验证码
- 可选项：真实姓名、邮箱、角色

### 2. 需求管理 (📋) - 5个接口

#### ✅ 创建需求
- 接口：`POST /api/demands`
- 功能：发布新的服务需求
- 必填项：标题、类型、描述、地址、日期、时间

#### ✅ 查询需求列表
- 接口：`POST /api/demands/query`
- 功能：按条件筛选需求
- 筛选条件：状态、类型、分页

#### ✅ 获取需求详情
- 接口：`GET /api/demands/{id}`
- 功能：查看单个需求的详细信息

#### ✅ 需求统计
- 接口：`GET /api/demands/statistics`
- 功能：获取需求统计数据
- 包含：总数、完成率、平均响应时间等

#### ✅ 热力图数据
- 接口：`GET /api/demands/heat-map`
- 功能：获取指定范围内的需求分布
- 参数：经纬度、半径(默认5000米)

### 3. 需求操作 (⚙️) - 6个接口

#### ✅ 更新需求
- 接口：`PUT /api/demands/{id}`
- 功能：修改需求信息
- 可更新：标题、描述等

#### ✅ 取消需求
- 接口：`POST /api/demands/{id}/cancel`
- 功能：取消已发布的需求

#### ✅ 接单
- 接口：`POST /api/demands/{id}/accept`
- 功能：志愿者接取需求

#### ✅ 开始服务
- 接口：`POST /api/demands/start-service`
- 功能：开始执行服务
- 参数：需求ID、服务凭证类型、凭证内容

#### ✅ 结束服务
- 接口：`POST /api/demands/end-service`
- 功能：完成服务
- 参数：需求ID、服务凭证类型、凭证内容

#### ✅ 分配暖龄币
- 接口：`POST /api/demands/distribute-warm-coin`
- 功能：分配获得的暖龄币
- 选项：
  - 自己保留
  - 转赠父母（需提供父母用户ID）
  - 捐赠公益池

### 4. 用户信息 (👤) - 5个接口

#### ✅ 获取当前用户信息
- 接口：`GET /api/users/me`
- 功能：查看当前登录用户的详细信息

#### ✅ 更新用户信息
- 接口：`PUT /api/users/{id}`
- 功能：修改用户资料
- 可更新：真实姓名、邮箱

#### ✅ 获取保存的地址
- 接口：`GET /api/users/{id}/saved-addresses`
- 功能：查看用户保存的地址列表

#### ✅ 添加保存的地址
- 接口：`POST /api/users/{id}/saved-addresses`
- 功能：添加新地址到收藏

#### ✅ 删除保存的地址
- 接口：`DELETE /api/users/{id}/saved-addresses`
- 功能：从收藏中删除地址

### 5. 暖龄币 (🪙) - 4个接口

#### ✅ 查看暖龄币记录
- 接口：`GET /api/warm-coin-records/me`
- 功能：查看个人暖龄币流水记录
- 支持：分页查询

#### ✅ 按类型查询记录
- 接口：`GET /api/warm-coin-records/me/type/{type}`
- 功能：查看特定类型的记录
- 类型：获得、支出、转账、公益

#### ✅ 查询需求相关记录
- 接口：`GET /api/warm-coin-records/demand/{demandId}`
- 功能：查看某个需求相关的暖龄币记录

#### ✅ 暖龄币统计
- 接口：组合调用
- 功能：查看总收入、总支出、余额

### 6. 消息中心 (💬) - 8个接口

#### ✅ 获取消息列表
- 接口：`GET /api/messages`
- 功能：查看所有消息
- 支持：分页查询

#### ✅ 按类型查询消息
- 接口：`GET /api/messages/type/{type}`
- 功能：筛选特定类型的消息
- 类型：系统消息、需求相关、暖龄币相关、亲属相关

#### ✅ 获取消息详情
- 接口：`GET /api/messages/{messageId}`
- 功能：查看单条消息详情

#### ✅ 获取未读数量
- 接口：`GET /api/messages/unread/count`
- 功能：查看未读消息数量

#### ✅ 标记消息为已读
- 接口：`PUT /api/messages/{messageId}/read`
- 功能：将单条消息标记为已读

#### ✅ 批量标记已读
- 接口：`PUT /api/messages/read`
- 功能：批量标记多条消息为已读

#### ✅ 删除消息
- 接口：`DELETE /api/messages/{messageId}`
- 功能：删除单条消息

#### ✅ 批量删除消息
- 接口：`DELETE /api/messages`
- 功能：批量删除多条消息

### 7. 亲属关系 (👨‍👩‍👧‍👦) - 9个接口

#### ✅ 获取亲属列表
- 接口：`GET /api/relatives`
- 功能：查看已关联的亲属列表

#### ✅ 获取待处理请求
- 接口：`GET /api/relatives/pending`
- 功能：查看收到的待处理关联请求

#### ✅ 获取已发送请求
- 接口：`GET /api/relatives/sent`
- 功能：查看自己发送的关联请求

#### ✅ 发送亲属请求
- 接口：`POST /api/relatives`
- 功能：向其他用户发送关联请求
- 参数：亲属用户ID、关系类型

#### ✅ 接受亲属请求
- 接口：`PUT /api/relatives/{requestId}/accept`
- 功能：接受关联请求

#### ✅ 拒绝亲属请求
- 接口：`PUT /api/relatives/{requestId}/reject`
- 功能：拒绝关联请求

#### ✅ 更新分享设置
- 接口：`PUT /api/relatives/{relativeId}/share`
- 功能：设置是否与该亲属分享需求

#### ✅ 删除亲属关系
- 接口：`DELETE /api/relatives/{relativeId}`
- 功能：解除亲属关系

#### ✅ 查找亲属关系
- 接口：`GET /api/relatives/check`
- 功能：查询与指定用户的关系

### 8. 权限测试 (🧪) - 5个接口

## 💡 使用指南

### 基础测试流程

1. **登录系统**
   ```
   方式1：用户名密码登录
   - 用户名: admin
   - 密码: admin123
   
   方式2：手机验证码登录
   - 手机号: 13800138000
   - 点击发送验证码
   - 输入验证码登录
   ```

2. **创建需求**
   ```
   - 填写需求标题、描述
   - 选择需求类型
   - 设置服务地址和时间
   - 设置暖龄币奖励
   - 点击创建
   ```

3. **查询需求**
   ```
   - 选择状态/类型筛选
   - 设置分页参数
   - 点击查询
   - 查看需求列表
   ```

4. **完整服务流程**
   ```
   发布者: 创建需求
      ↓
   志愿者: 接单
      ↓
   志愿者: 开始服务
      ↓
   志愿者: 结束服务
      ↓
   志愿者: 分配暖龄币
   ```

### 验证码测试

1. **首次发送**
   - 输入手机号
   - 点击发送
   - 应该成功，显示验证码

2. **60秒内再次发送**
   - 再次点击发送
   - 应该失败，提示"发送过于频繁，请XX秒后再试"
   - 按钮显示倒计时

3. **60秒后重新发送**
   - 等待倒计时结束
   - 再次点击发送
   - 应该成功

### 权限测试

1. **未登录状态**
   - 测试公共接口 → 成功
   - 测试用户接口 → 失败（401）

2. **登录后**
   - 测试公共接口 → 成功
   - 测试用户接口 → 成功
   - 测试管理员接口 → 根据角色

```

  ↓

  ↓
```

## 🐛 常见问题

### Q: 页面显示401错误？
A: 检查：
1. 是否已登录
2. Token是否有效
3. 该接口是否需要特定权限

### Q: 验证码发送失败？
A: 检查：
1. Redis服务是否运行
2. 手机号格式是否正确
3. 是否在60秒限制内

### Q: 看不到返回数据？
A: 
1. 打开浏览器控制台(F12)
2. 查看Network标签
3. 检查API响应内容

### Q: 某些功能无法使用？
A:
1. 确认后端服务正常运行
2. 确认数据库数据正确
3. 查看后端日志
